# Saturn roadmap

- [x] Phase 0 — Rust project, Saturn desktop shell, initial directories, Windows CI workflow
- [x] Phase 1 — Local/offline profile management and persistence
- [ ] Phase 2 — Minecraft version manifest, classifier and category filters
- [ ] Phase 3 — Reliable downloader and isolated version installer
- [ ] Phase 4 — Java runtime manager and optional minimized custom JRE
- [ ] Phase 5 — Minecraft launch engine
- [ ] Phase 6 — Integration testing, polish and release workflow

Each phase should keep the project buildable and testable on Windows x64.
